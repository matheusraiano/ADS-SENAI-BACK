    Linguagem Compilada:
        O computador traduz todo o programa para um arquivo executável antes do uso. Isso deixa o programa muito rápido na hora de rodar.
        O código vira um arquivo pronto para o computador.
        A execução é rápida.Erros de código aparecem antes de o programa rodar.
        Exemplos: C, C++ e Rust.

    Linguagem Interpretada:
        O interpretador lê o código fonte e executa cada comando na mesma hora, sem criar um arquivo executável separado.
        O programa roda direto do código original.
        A execução é mais lenta.O erro só aparece na hora em que o programa chega naquela linha.
        Exemplos: Python, JavaScript e Ruby.

    Linguagem Híbrida:
        O código passa por uma primeira tradução rápida para um formato intermediário (como um bytecode). Depois, uma máquina virtual lê esse formato e executa no computador.
        Junta a velocidade de preparo com a facilidade de uso.
        Roda em vários sistemas diferentes com a mesma facilidade.
        Exemplos: Java e C#.

    O que é o Polimorfismo:
        Conceito básico: 
            Permite chamar um método com o mesmo nome em várias classes, mas cada classe executa uma ação própria.
        Exemplo prático: 
            Pense no comando falar(). Um gato mia, um cachorro late e uma pessoa conversa. Todos usam o mesmo nome de método, mas o comportamento muda conforme o objeto.
        Flexibilidade: 
            O código principal não precisa saber o tipo exato do objeto para usá-lo, apenas que ele possui aquele método
    Tipos Principais de Polimorfismo:
        Dinâmico (Sobrescrita / Overriding): 
            Ocorre em tempo de execução. A subclasse reescreve um método herdado da superclasse para dar a ele uma nova forma de funcionamento.
        Estático (Sobrecarga / Overloading): 
            Ocorre em tempo de compilação. Permite criar vários métodos com o mesmo nome na mesma classe, mas com quantidades ou tipos de parâmetros diferentes.
