    Linguagem Compilada:
        O computador traduz todo o programa para um arquivo executável antes do uso. Isso deixa o programa muito rápido na hora de rodar.
        O código vira um arquivo pronto para o computador.
        A execução é rápida.Erros de código aparecem antes de o programa rodar.
        Exemplos: C, C++ e Rust.

    Linguagem Interpretada:
        O interpretador lê o código fonte e executa cada comando na mesma hora, sem criar um arquivo executável separado.
        O programa roda direto do código original.
        A execução é mais lenta.O erro só aparece na hora em que o programa chega naquela linha.
        Exemplos: Python, JavaScript e Ruby.

    Linguagem Híbrida:
        O código passa por uma primeira tradução rápida para um formato intermediário (como um bytecode). Depois, uma máquina virtual lê esse formato e executa no computador.
        Junta a velocidade de preparo com a facilidade de uso.
        Roda em vários sistemas diferentes com a mesma facilidade.
        Exemplos: Java e C#.
